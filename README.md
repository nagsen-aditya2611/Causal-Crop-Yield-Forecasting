# Causal Crop Yield Forecasting

A research-oriented project on causal reasoning for crop yield forecasting using causal discovery, causal inference, machine learning, and deep learning.

## Objectives

- Explore causal reasoning in agriculture
- Apply causal discovery algorithms (PC/PCMCI)
- Estimate treatment effects using causal inference
- Compare causal and traditional predictive models
- Improve interpretability for agricultural decision support
